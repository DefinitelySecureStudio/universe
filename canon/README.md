# Canon records

This directory contains cross-cutting canon indexes and explicit public change
records that cannot be represented as a simple additive edit.

- [`changes/`](changes/) preserves corrections, deprecations, and retcons.
- Proposals are non-canonical until approved and merged into `main`.
- Current canon is the latest non-superseded record in a tagged canon release.

Do not use canon records to hint at or negate unrevealed lore.
