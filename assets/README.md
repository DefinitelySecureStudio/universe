# Public assets

Web-ready story assets explicitly approved for public distribution may live
here. Organize them by canonical record or publication ID and include provenance,
checksum, media type, dimensions, accessibility text, and rights metadata.

Do not commit high-resolution masters, editable sources, unpublished artwork,
production reference, private storage URLs, or assets with unclear third-party
rights. Repository visibility does not grant reuse rights; each asset follows its
documented terms.
