# Security and spoiler-disclosure policy

## Reporting private-material exposure

Do not open a public issue for an accidental spoiler, hidden lore, unpublished
artwork, credential, personal data, or other confidential material. Do not quote
or attach the exposed content in public discussion.

Use GitHub's private vulnerability reporting:

<https://github.com/DefinitelySecureStudio/universe/security/advisories/new>

Identify the affected path and revision, describe the exposure without repeating
unnecessary sensitive details, and explain where the material may have been
copied or published. Maintainers will coordinate containment, history repair when
appropriate, downstream removal, reader communication, and disclosure timing.

## Supported versions

The current canon release and any explicitly supported prior release receive
security and accidental-disclosure corrections. A support table will be added
with the first tagged canon release.
