# Published comics

Reader-safe metadata for published *Definitely Secure* episodes belongs here.
One episode uses one permanent `DS-NNNN` record and the display title
`Definitely Secure #NNNN — Episode Title`.

Copy [`_template.md`](_template.md) only after an episode is approved for public
release. Working titles, unpublished scripts, draft artwork, private manifests,
and planned publication dates do not belong here.
